reflections is used for 2 purpose

	

1. To explore the metadata from an .dll or .exe
	want to know what are the Namespaces in this exe/dll
	what are the classes
	What are the properties
	What are the list of methods
	What are the list of parameters?
	What are constructors 
	What are the list of Enum

	By using system.runtime.reflection

2. To create the object at runtime, by user choice
	eg. if my bankingLib has 200 classes / types of accounts
		very bad programming to use if conditions or switch case

		if we want to remove / discontinue some accounts we will have to make changes to exe/dll
		if we want to add  new account we will have to do the same

		this is not possible

		user can choose which account they want to create, select it and create the object at runtime
