			this container application information like
				which language  - c#
				which framework - .net core 10.0
				platform - windows / Linux / max
				etc....

				how they communicate to eachother, so it creates a network for communication

			and 2 simple commands with docker-componse
			docker-compose --up (this will start all the 3 apps, based on sequence mentioned, create network etc..)

		what is a microservice 
			break down your big application into small applications
			modules of your application into small applications (microservice)

			the application you have created so far in last 6 weeks is called as monolithic application

		-- once we test - we push it to repository (dockerhub - public repo / azure container registry - private repo)
