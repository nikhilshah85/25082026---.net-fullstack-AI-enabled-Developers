Account
	Subscription (you can have multiple subscriptions for account)
		     Resource Group (this is the drving force for your resource)
			RG - is like a package/bundle which will group all the parts of your service

				eg. Virtual Machine is made up of 
					Disk	
					Network
					RAM
					CPUS
					security unit like firewall
					scheduler (eg. shut down the machine at 6:00 PM EST everday)
					etc....
			1. resource group can have multiple vms, databases, storage accounts etc..


			if you wish to delete everything, just delete the resource group
			if you wish to setup a spending limit set it at a resource group
