2. create a new console application - empAPP
	dotnet new console --name empAPP

3. install ef core sql server package (because we are working with sql server)
	dotnet add package Microsoft.EntityFrameworkCore.SqlServer



4. install ef core designer package
	dotnet add package Microsoft.EntityFrameworkCore.Design

5. install ef core cli (this needs to be done only 1ce per machine)
	dotnet tool install --global dotnet-ef

6. test the version and installation of ef core cli
	dotnet ef  

7. ready the connection string to server
		(this is for server authentication)
	server=;database=;username=;password=;trustservercertificat=true
 		(this is for windows authentication)
	server=;database=;Trusted_Connection=true;trustservercertificat=true


	server=NIKHILPC\MUMBAISERVER;database=employeeManagementNewDB;Trusted_Connection=true;trustservercertificat=true


8. we are now set to scaffold the database to application
		     (map)
	we will now get a presence of database into our application
		database = dbContext (we will get a class called dbContext)
		tables = dept.cs and empoyees.cs (this are mapping to our tables and views)
				this classes will have properties mapped to columns in table



	========================================================================================================
	dotnet ef dbcontext scaffold "connection string" Microsoft.EntityFrameworkCore.SqlServer --output-dir DB

	========================================================================================================
